# Support

Modernized React support app.

## Stack

- React 19.3
- React Router 7
- Vite 8
- Bootstrap 5.3
- i18next 26
- react-i18next 17
- Font Awesome 7

## Requirements

Node.js 22.12.0 or newer.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## GitHub Pages

```bash
npm run deploy
```

The project uses `HashRouter`, so routes continue to work on GitHub Pages.
